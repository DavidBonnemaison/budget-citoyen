## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | convert.py — YAML parsing | mitigate | JSON Schema Draft 2020-12 validation gate before ANY JSON is written. Missing `description`, wrong value types, malformed date keys all cause hard failure. Research suggests per-file validation is the standard for Rules as Code pipelines. |
| T-01-02 | Tampering | convert.py — output artifact | mitigate | SHA-256 integrity hashes computed on output JSON (Plan 04 Task 2 enforces this in CI). Build is reproducible — same YAML input always produces same JSON output (deterministic PyYAML safe_load + deterministic json.dump with sort_keys). |
