  <implementation>
    File: packages/data-pipeline/src/synthetic_pop/insee_loader.py

    Create an InseeAggregateLoader class with:
    1. Constructor: `__init__(self, seed: int = 42, num_rows: int = 50000)` — stores seed and target row count
    2. `load(self, source_path: Optional[str] = None) -> pd.DataFrame` — main entry point implementing the D-03 tabular interface

    The load() method logic:
    a. If source_path is provided and exists, attempt to read INSEE tables (CSV/Excel). If no source or parsing fails, fall through to synthetic generation from known French statistical distributions.
    b. Synthetic generation (the default/fallback path): Use numpy seeded with self.seed to construct 50K rows matching published INSEE marginal distributions.
    c. For each of the 8 canonical COLUMNS:
       - profile_id: sequential integers 1..num_rows
       - age: sample from French age pyramid distribution (beta distribution scaled to 18-100, mode ~45). Use `numpy.random.default_rng(seed).beta(a=2.5, b=3.0, size=num_rows) * 82 + 18`
       - patrimoine: sample from log-normal distribution matching Enquête Patrimoine data (median ~€115K, mean ~€230K). Use `np.exp(rng.normal(loc=11.65, scale=1.2, size=num_rows))` clipped to [0, 10M]
       - revenu_fiscal: sample from gamma distribution matching ERFS data (median ~€22K, mean ~€30K). Use `rng.gamma(shape=2.0, scale=15000, size=num_rows)` clipped to [0, 500K]
       - situation_familiale: sample from published distribution (~40% marie, ~30% celibataire, ~10% divorce, ~8% pacse, ~7% veuf, ~5% separe) using `rng.choice(SITUATION_FAMILIALE_VALUES, size=num_rows, p=[0.30, 0.40, 0.08, 0.07, 0.10, 0.05])`
       - nombre_parts: derive from situation_familiale + random children count. Married/PACSed → 2.0 base + 0.5 per child. Celibataire → 1.0 base + 0.5 per child. Children = rng.poisson(lam=1.2) clipped to 0-19 per household. Round to nearest 0.5, clamp to [1.0, 10.0]
       - type_activite: sample from employment distribution (~45% salarie, ~21% retraite, ~8% independant, ~6% fonctionnaire, ~7% chomeur, ~8% etudiant, ~5% inactif)
       - zone_residence: sample (~19% zone1 Île-de-France, ~28% zone2 grandes villes, ~53% zone3 reste du territoire)

    d. Apply age-conditional adjustments: older profiles (age >= 65) have higher probability of retraite, lower revenu_fiscal. Young profiles (age < 25) have higher probability of etudiant/chomeur.
    e. Return the DataFrame.

    The module should also export a standalone function `build_insee_dataframe(num_rows: int = 50000, seed: int = 42) -> pd.DataFrame` that skips file loading and directly builds the synthetic dataset. This is used by the test suite and as the pipeline entry point.

    Key: Comment all distribution parameters with their INSEE source (e.g., "INSEE Recensement 2023 — age pyramid", "INSEE ERFS 2021 — revenu_fiscal decile distribution") so the methodology is auditable.

    Dependencies: numpy, pandas (already installed). No new packages needed.
