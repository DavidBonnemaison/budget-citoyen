## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| TypeScript types ↔ JSON data | Deserialization boundary — Profile interface must match JSON schema exactly | Population profile records |
| External data file → insee_loader.py | Untrusted input from user-supplied CSV/Excel source_path | Aggregate INSEE data |
| insee_loader.py → preprocess.py | DataFrame output crossing module boundary; must match COLUMNS contract | Training features |
| calibrate.py output → macro-interpolate.ts | Calibrated grid crosses Python→TypeScript via Parquet; grid convention mismatch risk | Shock matrix grid |
| calibrate.py → export_parquet.py | Grid values must be validated (finite, non-NaN) before PyArrow export | Float32 grid values |
| External IRF/elasticity sources → calibrate.py | Published IRFs/elasticities are hardcoded constants, not dynamically loaded | Public calibration coefficients |
| InseeAggregateLoader → preprocess.py | Training data crosses module boundary; validate columns, ranges, nulls | 50K row training set |
| train.py → CopulaGAN model checkpoint | Model file written to disk — local file, tampering detectable via quality report | synthesizer.pkl |
| evaluate.py → quality_report.json | Quality scores written to disk; validated before CI acceptance gate | SDMetrics scores |
| population-v2025.1.json → PopulationCache.fromDoc() | Untrusted JSON crosses into typed TypeScript; structure validated before cache construction | 50K synthetic profiles |
| WorkerOrchestrator postMessage → PopulationCache.fromDoc() | Serialized JSON across main-thread→worker boundary (structured clone) | PopulationDoc |
| synthetic_df → inject_dp_privacy() | Unvalidated DataFrame enters DP injection — synthetic data only, no real PII | Aggregate statistics |
| dp_report → .meta.json | DP proof metadata written to disk; tamper-evident via SHA-256 | ε proof, mechanism, timestamp |
| .meta.json → methodology page (Phase 3) | DP attestation displayed to users; must be machine-verifiable | ε ≤ 1.0 proof |
| dp_inject.py ↔ OpenDP 0.14.2 | Formal ε proof relies on OpenDP library integrity; pinned in pyproject.toml | make_basic_composition |
| orchestrator.ts → citizen-worker.ts postMessage | Serialized JSON crosses main-thread→worker boundary via structured clone | populationJson string |
| population-v2025.1.json (string) → JSON.parse in worker | Untrusted JSON deserialization; PopulationCache.fromDoc() is validation entry point | JSON payload |
| generate_dist.py → calibrate_and_export() | Orchestrator script to calibration module; internal Python boundary | Calibration config |
| generate_dist.py → generate_from_insee() | Orchestrator script to synthetic population pipeline; internal Python boundary | Training config |
| shock-matrix-integration.test.ts → macro-interpolate.ts | Test fixture data crosses to production interpolation engine | Public calibration coefficients |
| generate_dist.py → dist/ artifacts | Output artifacts written to filesystem; must be valid and within size limits | Parquet, JSON, .meta.json |
| Python venv → pip registry | Package integrity during pip install — offline pipeline only | sdv, opendp, sdmetrics |
| profile.revenu_fiscal → decile computation | Numeric value for percentile computation; must handle edge cases | 50K × float64 values |

## Threat Register

### Plan 01 — Types & Data Contracts (T-02.2-01 through T-02.2-03)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-01 | Tampering | pip install sdv/opendp/sdmetrics | accept | Pinned versions; offline pipeline only; no runtime exposure | closed |
| T-02.2-02 | Information Disclosure | types.ts Profile interface | mitigate | Interface is contract only — no data flows through at definition time. PopulationCache never exposes individual profiles to network per D-12 | closed |
| T-02.2-03 | Spoofing | Wave 0 test stubs | accept | Placeholder tests replaced by real tests in Wave 2 TDD plans; no runtime impact | closed |

### Plan 02 — INSEE Loader (T-02.2-04 through T-02.2-06)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-04 | Tampering | insee_loader.py file input | mitigate | Use pandas read_csv/read_excel with safe defaults. Column validation before returning DataFrame. No eval() or shell commands on file contents | closed |
| T-02.2-05 | Information Disclosure | num_rows parameter | accept | num_rows is configuration, not PII. Loader generates synthetic data from aggregates | closed |
| T-02.2-06 | Denial of Service | Large num_rows | mitigate | MAX_ROWS=100000 enforced in constructor. ValueError on num_rows > 100000. Memory bounded at ~3MB for 50K rows | closed |

### Plan 03 — Calibration Engine (T-02.2-07 through T-02.2-10)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-07 | Tampering | calibrate.py grid values | mitigate | np.isfinite + non-NaN validation before export. Grid convention cross-checked against macro-interpolate.ts. SHA-256 in .meta.json | closed |
| T-02.2-08 | Tampering | Parquet file substitution | mitigate | .meta.json sidecar with grid_shape, breakpoints, convex_hull metadata + SHA-256 hash for downstream cross-validation | closed |
| T-02.2-09 | Information Disclosure | Hardcoded elasticity values | accept | Public budget parameters per D-07 methodology; transparently documented; not secrets or PII | closed |
| T-02.2-10 | Denial of Service | Grid size explosion | mitigate | Grid fixed at 12³ × 4 = 6,912 Float32 (~27KB). build_cartesian_grid enforces MAX_DIMENSIONS=4. Export size verified by test | closed |

### Plan 04 — Synthetic Population Generation (T-02.2-11 through T-02.2-14)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-11 | Tampering | InseeAggregateLoader output | mitigate | preprocess_real_data() clips and validates input ranges. train.py enforces enforce_min_max_values=True. Test validates categorical values and nulls | closed |
| T-02.2-12 | Tampering | Model checkpoint (synthesizer.pkl) | accept | Local file for regeneration only. SHA-256 hash of output JSON provides downstream integrity. Model tampering caught by quality report degradation | closed |
| T-02.2-13 | Information Disclosure | Synthetic training data | accept | Aggregate-derived training data — no real individual records. DisclosureProtectionEstimate validates non-reversibility | closed |
| T-02.2-14 | Denial of Service | Full-scale training (500 epochs × 50K rows) | mitigate | Full training marked @pytest.mark.slow, excluded from CI. CI uses epochs=10, num_rows=2000. Configurable parameters | closed |

### Plan 05 — PopulationCache (T-02.2-15 through T-02.2-18)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-15 | Tampering | population-v2025.1.json integrity | mitigate | SHA-256 hash in doc.meta validated against JSON content before cache construction. fromDoc() accepts pre-validated docs | closed |
| T-02.2-16 | Denial of Service | Malformed PopulationDoc with massive profiles array | mitigate | O(n) memory only (~10MB for 50K profiles). Warning logged if profileCount > 100000. Bounded by data contract | closed |
| T-02.2-17 | Information Disclosure | getProfilesByDecile() exposing individual profiles | accept | Intended API for Phase 4 distributional analysis. No network exposure per D-12. Profiles already in worker memory | closed |
| T-02.2-18 | Information Disclosure | Decile boundaries leaking individual revenu_fiscal | accept | Decile boundaries are aggregate statistics (threshold values), not individual values. DP-noised in Plan 06 | closed |

### Plan 06 — Differential Privacy (T-02.2-19 through T-02.2-22)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-19 | Tampering | DP proof falsification (manual epsilon) | mitigate | dp_epsilon derived programmatically from OpenDP composed.map(d_in=1). SHA-256 hash in sidecar covers JSON — post-hoc modification detectable | closed |
| T-02.2-20 | Information Disclosure | DP noise insufficient to protect aggregates | mitigate | ε ≤ 1.0 with formal proof. Noise on aggregates only (D-10). Sequential composition via make_basic_composition prevents budget double-spending | closed |
| T-02.2-21 | Tampering | population-v2025.1.json substitution | mitigate | SHA-256 hash in .meta.json. Downstream PopulationCache.loadFromJSON() verifies hash per D-14. Phase 3 Service Worker SRI adds defense-in-depth | closed |
| T-02.2-22 | Repudiation | DP proof timestamp manipulation | mitigate | dp_proof_timestamp set to UTC ISO 8601 at generation time. Git commit timestamp provides independent verification | closed |

### Plan 07 — Worker Orchestrator (T-02.2-23 through T-02.2-26)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-23 | Tampering | populationJson string in transit (orchestrator → worker) | accept | postMessage uses structured clone; browser runtime guarantees message integrity between same-origin contexts. No network boundary | closed |
| T-02.2-24 | Denial of Service | Malformed JSON passed to PopulationCache.fromDoc() | mitigate | JSON.parse throws on invalid JSON → caught by try/catch → ERROR response. Orchestrator's pending.reject handles the ERROR | closed |
| T-02.2-25 | Information Disclosure | populationJson logged to console | mitigate | No console.log of populationJson payload. Only message types and IDs used in debug logging. Verifiable via grep | closed |
| T-02.2-26 | Elevation of Privilege | init() called multiple times with different populationJson | accept | Intentional — Phase 3 UI may re-initialize with different data (e.g., switching reference years). Previous cache replaced via variable reassignment | closed |

### Plan 08 — Pipeline Orchestration (T-02.2-27 through T-02.2-30)

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-02.2-27 | Tampering | generate_dist.py step ordering (overwrite risk) | mitigate | Step 6 replaces Step 5 stub explicitly. Step 7 creates new files; never overwrites existing shock matrix. Distinct file paths: shockmatrix-*.parquet vs population-*.json | closed |
| T-02.2-28 | Denial of Service | Pipeline runtime >20 min | accept | ~15-25 min for full pipeline training. Acceptable for offline CI. Steps 1-5 complete quickly (~30s) even if Steps 6-7 fail (graceful degradation) | closed |
| T-02.2-29 | Information Disclosure | Test matrix revealing calibration coefficients | accept | Test matrix uses public calibration coefficients documented per D-07 methodology. Public domain economic parameters | closed |
| T-02.2-30 | Elevation of Privilege | Arbitrary Python module execution | mitigate | Only imports from project-owned modules with explicit function calls. No eval(), exec(), or dynamic module loading from user input | closed |
