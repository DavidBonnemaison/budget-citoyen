## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| InseeAggregateLoader → preprocess.py | Training data crosses module boundary — validate columns, ranges, and nulls before training |
| train.py → CopulaGAN model checkpoint | Model file written to disk — vulnerable to tampering if models/ directory is writable by untrusted processes |
| evaluate.py → quality_report.json | Quality scores written to disk — must be validated before CI acceptance gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.2-11 | Tampering | InseeAggregateLoader output | mitigate | preprocess_real_data() clips and validates all input ranges. train.py enforces enforce_min_max_values=True. Test 7 validates categorical values. Null check in Test 2. |
| T-02.2-12 | Tampering | Model checkpoint (synthesizer.pkl) | accept | Model checkpoint is a local file used only for regeneration. SHA-256 hash of output JSON (Plan 06) provides integrity verification downstream. Model file tampering would be caught by quality report degradation. |
| T-02.2-13 | Information Disclosure | Synthetic training data | accept | Training data is aggregate-derived — no real individual records. DisclosureProtectionEstimate (Test 8) validates that synthetic data cannot be reverse-engineered to identify real individuals. |
| T-02.2-14 | Denial of Service | Full-scale training (500 epochs × 50K rows) | mitigate | Full training is marked @pytest.mark.slow and excluded from CI. CI tests use epochs=10, num_rows=2000. generate_from_insee() accepts configurable epochs/num_rows parameters. |
</threat_model>
