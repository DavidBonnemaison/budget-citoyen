<objective>
Create the Vega-Lite chart specification layer for all four macro trajectory series. Defines shared SVG pattern fills (diagonal lines, dots, crosshatch, vertical lines) with deuteranopia-safe colors, a shared Vega-Lite configuration enforcing ARIA labels and consistent typography, and four declarative chart specs (deficit, debt, GDP growth, employment) ready for data injection at render time.

Purpose: Every chart rendered in Phase 3 depends on these specs existing — they are the "contract" that ChartCell components consume. The pattern-based differentiation ensures RGAA 4 compliance (A11Y-03: never color alone) and the `description` channel enables automatic `aria-label` generation on SVG output (A11Y-01).
Output: Six TypeScript modules in `webapp/src/charts/` — patterns, config, and four Vega-Lite `TopLevelSpec` exports with empty data arrays, ready for ChartGrid to populate with MacroResult trajectories.
</objective>
