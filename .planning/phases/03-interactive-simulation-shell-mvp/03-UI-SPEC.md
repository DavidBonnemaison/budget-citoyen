# Phase 3 — UI Design Contract

> Visual and interaction contract for the Citizen Explorer MVP. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable — STACK.md explicitly rejects shadcn/Radix (see "What NOT to Use") |
| Component library | React Aria (hooks for interactive controls: `useSlider`, `useButton`, `useToggle`, `useAccordion`) |
| Icon library | lucide-react (tree-shakeable, accessible SVG icons with `aria-hidden="true"` by default) |
| Font | System font stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`. No web font download — maximizes performance for the <1s warm / <3s cold load targets (D-31). |

**Rationale for no shadcn:** STACK.md §"What NOT to Use" — "Radix primitives provide good accessibility basics but lack the advanced screen-reader value formatting and internationalization that React Aria's `useSlider` provides for range sliders." React Aria's `useSlider` hook is mandatory for RGAA 4 Thématique 11 compliance (A11Y-05). Tailwind CSS 4.3 utility classes style the unstyled React Aria components directly.

## Spacing Scale

Declared values (multiples of 4, standard 8-point scale):

| Token | Value | Tailwind Class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon gaps, tight inline padding, chart legend spacing |
| sm | 8px | `gap-2`, `p-2` | Compact element spacing, scenario card internal padding |
| md | 16px | `gap-4`, `p-4` | Default element spacing, slider-to-label gap, section internal padding |
| lg | 24px | `gap-6`, `p-6` | Section padding, panel internal padding, card gap |
| xl | 32px | `gap-8`, `p-8` | Layout gaps, split panel gutter |
| 2xl | 48px | `gap-12`, `p-12` | Major section breaks |
| 3xl | 64px | `gap-16`, `p-16` | Page-level spacing, top/bottom page margins |

**Exceptions:**

| Token | Value | Usage | Reason |
|-------|-------|-------|--------|
| touch-target | 44px | All interactive controls on mobile (slider thumbs, buttons, scenario cards) | UI-06: "points de touche ≥ 44px" |
| panel-width | 380px | Left panel (scenario selector + sliders) on desktop | D-22: "fixed width ~380px" |

## Typography

| Role | Size | Weight | Line Height | Tailwind Classes | Usage |
|------|------|--------|-------------|------------------|-------|
| Body | 16px | 400 | 1.5 | `text-base font-normal leading-relaxed` | All citizen-facing paragraph text, economic term definitions, tooltip content |
| Label | 14px | 400 | 1.4 | `text-sm font-normal leading-snug` | Slider value labels, chart axis labels, footnote text, methodology page body |
| Heading | 22px | 600 | 1.3 | `text-xl font-semibold leading-tight` | Section titles, panel headers, chart titles, scenario card names |
| Display | 32px | 600 | 1.2 | `text-3xl font-semibold leading-none` | Page title ("Budget Citoyen"), household impact value (€/mois), splash screen logo area |

**Rationale:** 4 sizes, 2 weights (400 + 600) — fits the contract requirement. 16px body at weight 400 with 1.5 line height supports the D-26 "niveau lycée (16-18 ans)" readability requirement. 14px labels maintain information density without sacrificing readability. No italic usage — clean, institutional typography.

## Color

### Semantic Palette

| Role | Hex | Usage |
|------|-----|-------|
| Dominant (60%) | `#F8FAFC` | Page background, main content area background |
| Secondary (30%) | `#F0F4F8` | Cards (scenario cards, profile pill cards), sidebar/left panel background, nav background |
| Accent (10%) | `#1E3A5F` | **Reserved exclusively for:** primary button fills, slider thumb fill, slider track active side, active/hover states on interactive elements, selected scenario card border, logo area, page title |
| Destructive | `#DC2626` | **Reserved exclusively for:** destructive action buttons (see Copywriting Contract), error state icons/text, reset button hover state |

**Accent reserved-for list (no other usage):**
1. Primary button background fill (`<button>` CTA, "Réessayer" button in error state)
2. Slider thumb fill (`useSlider` — the draggable handle)
3. Slider track active side (the filled portion from 0% to the thumb)
4. Active/hover states on interactive elements (scenario card hover, profile pill selection)
5. Selected scenario card border (`ring-2` or `border-2`)
6. Logo area and page title ("Budget Citoyen" heading)
7. Focus rings (`outline-2 outline-offset-2` for keyboard navigation)

**What accent does NOT cover:** Chart colors, link text (use WCAG-compliant blue), info badges, decorative elements, background gradients.

### Text Colors

| Role | Hex | Usage |
|------|-----|-------|
| Text primary | `#0F172A` | Body text, headings, slider labels — WCAG AAA contrast on `#F8FAFC` (18.2:1) |
| Text secondary | `#475569` | Descriptions, footnotes, methodology attributions — WCAG AA contrast (5.3:1) |
| Text on accent | `#FFFFFF` | Text on accent-filled buttons/thumb | 
| Text disabled | `#94A3B8` | Disabled sliders, placeholder text in empty state |

### Chart Palette (RGAA 4 — Deuteranopia-safe)

| Series | Color | Pattern | Usage |
|--------|-------|---------|-------|
| Deficit (%PIB) | `#0072B2` | Diagonal lines (`pattern` → `path` at 45°) | Top-left chart |
| Debt (%PIB) | `#E69F00` | Dots (`pattern` → `circle` fill) | Top-right chart |
| GDP growth (%) | `#009E73` | Crosshatch (two crossed 45° paths) | Bottom-left chart |
| Employment (K) | `#CC79A7` | Vertical lines (`pattern` → `rect` stripes) | Bottom-right chart |

**RGAA 4 compliance (D-19, A11Y-03):** Each series uses a distinct SVG `<pattern>` fill PLUS a distinct color from the Wong (2011) deuteranopia-safe palette. Never color alone. Pattern fills are defined as `<defs>` within each chart's SVG and referenced via `fill="url(#pattern-defecit)"`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Choisir un scénario" — displayed as prompt above scenario card grid in empty/preselect state |
| Empty state heading | "Bienvenue sur le simulateur budgétaire" |
| Empty state body | "Choisissez un scénario pour commencer. Vous pourrez ensuite ajuster les paramètres fiscaux et visualiser leur impact sur votre pouvoir d'achat et l'économie nationale." |
| Empty state chart placeholder | "Sélectionnez un scénario pour voir les projections." — displayed in place of 2×2 chart grid |
| Empty state impact placeholder | "—" — displayed where household impact figures would appear |
| Loading state (splash) | "Chargement du simulateur…" — with subtext showing progress: "Récupération des données…" then "Initialisation du moteur de simulation…" |
| Loading state (slider computation) | No text — subtle opacity pulse (CSS transition, ~300ms ease) on affected chart areas. Slider value labels update instantly. |
| Error state (fetch failure) | Heading: "Impossible de charger les données." Body: "Vérifiez votre connexion internet et réessayez." Button: "Réessayer" |
| Error state (out-of-bounds macro) | "Paramètres hors domaine de validité" — overlay on greyed-out chart area (D-21). Warning message from `MacroResult.warningMessage` displayed above charts. |
| Reset button | "Réinitialiser" — resets all sliders to 0% (baseline 2025), deselects active scenario (D-14) |
| Reset confirmation | None — reset is a moderate action returning to baseline state. No destructive data loss. Immediate execution, no confirmation dialog needed. |
| Scenario card hover | Scenario name + brief fiscal summary visible on card. Selection shows `ring-2` accent border. |
| Micro result footnote | "Basé sur les scénarios les plus proches." — displayed below household impact figures (D-04) |
| Share button | "Partager" — copies state-encoded URL to clipboard. Confirmation toast: "Lien copié !" |
| Advanced mode toggle | "Mode avancé" — toggles display of individual bracket/parameter sliders (D-09, D-11) |
| Methodology page link | "Méthodologie et sources" — persistent footer link to `/methodologie` (D-25) |
| Household profile labels | "Foyer modeste" (SMIC ~14K€), "Foyer médian" (~26K€), "Foyer aisé" (~60K€) — D-06 |

**Tone:** Niveau lycée (16-18 ans) reading level throughout (D-26). Short sentences, active voice. Use "vous"/"votre" for direct citizen address. Economic terms have inline tooltip definitions (e.g., "PIB" → "tout ce que la France produit en un an").

**Destructive actions:** None in this phase. The "Réinitialiser" button returns to a known-good baseline state — no data is permanently lost. Marked as moderate impact, no confirmation dialog needed.

## Interactive Component Contracts

### Slider (`useSlider` from React Aria)

| Attribute | Value |
|-----------|-------|
| `aria-valuenow` | Current slider value (percentage change from baseline) |
| `aria-valuemin` | -30% (or lever-specific minimum) |
| `aria-valuemax` | +30% (or lever-specific maximum) |
| `aria-valuetext` | Formatted as: "{+X%} — Taux: {computed rate}%" or "{−X%} — Taux: {computed rate}%" |
| Keyboard support | Arrow keys (±1%), Page Up/Down (±5%), Home (min), End (max) |
| Throttle | ~50ms / 20 updates per second during drag (D-15) |
| Debounced ARIA announcement | On drag-end only — no screen reader chatter during continuous dragging (A11Y-05, D-15) |
| Baseline notch | Gentle snap at 0% center position. Label: "Actuel" (D-13) |
| Disabled state | Greyed out with `cursor-not-allowed` and `opacity-50` before scenario selection (D-28) |
| Touch target | ≥ 44px thumb size on all breakpoints (UI-06) |
| Value label | Updates instantly during drag (no computation needed). Shows: percentage change + resulting rate. |

### Scenario Card

| Attribute | Value |
|-----------|-------|
| Layout | Responsive grid: 3-column on desktop, 2-column on tablet, single-column on mobile |
| Card content | Scenario name (bold), brief description (2-3 lines max), default fiscal position indicators |
| Hover state | Background shift to `#F0F4F8`, subtle scale (1.02) |
| Selected state | `ring-2` with accent `#1E3A5F` border, slight elevation (`shadow-md`) |
| Keyboard | Tab-navigable, Enter/Space to select |
| Touch target | ≥ 44px minimum card height |

### Chart Grid (2×2 Vega-Lite)

| Attribute | Value |
|-----------|-------|
| Desktop layout | 2×2 grid (`grid-cols-2`), each cell equal height |
| Mobile layout | Stacked vertically, each chart full-width |
| SVG accessibility | `role="img"` on `<svg>`, `aria-labelledby` pointing to chart title (A11Y-01) |
| HTML fallback | Each chart has a sibling `<table>` with `<th scope="col">` / `<th scope="row">` markup, visually hidden but available to screen readers (A11Y-02) |
| Pattern fills | 4 distinct SVG `<pattern>` elements defined in `<defs>`, one per series (A11Y-03, D-19) |
| Tooltip | Hover tooltip showing precise value + series name. Touch: tap to show/hide tooltip (D-20) |
| Legend | Interactive: hover highlights selected series, dims others. Below each chart. |
| Out-of-bounds | Greyed-out overlay + "Paramètres hors domaine de validité" text (D-21) |

### Household Impact Display

| Attribute | Value |
|-----------|-------|
| Layout | 3 compact cards/pills side by side: "Foyer modeste", "Foyer médian", "Foyer aisé" |
| Content | Profile label, monthly income amount, ±€/mois impact with color coding (green = gain, red = loss, not color alone — also uses "+"/"−" prefix) |
| Mobile | Horizontal scroll or stacked pills |
| Update | Values update within 200ms of slider release (D-15) |
| Footnote | "Basé sur les scénarios les plus proches." in 14px secondary text below |

## State Machine

```
  ┌──────────┐
  │  LOADING │ ← Splash screen: asset fetch + worker init (D-27)
  └────┬─────┘
       │ workers report READY
       ▼
  ┌──────────────┐
  │   PRESELECT  │ ← Empty state: scenario cards grid + prompt (D-28)
  │ (empty state)│    Sliders disabled. Charts show placeholder.
  └──────┬───────┘
         │ user selects a scenario card
         ▼
  ┌──────────────┐
  │  SCENARIO    │ ← Scenario selected: household impact displays instantly
  │  DISPLAYING  │    (O(1) HashMap lookup). Sliders auto-positioned to
  └──────┬───────┘    scenario values (D-05, D-07).
         │
    ┌────┴────┐
    │         │
    ▼         ▼
┌───────┐ ┌──────────┐
│DRAG   │ │ RESET    │ ← "Réinitialiser" button: all sliders → 0%
│ACTIVE │ │          │    deselect scenario → return to PRESELECT (D-14)
└───┬───┘ └──────────┘
    │
    │ throttled updates + correlation ID discarding (D-15)
    ▼
┌──────────────┐
│  COMPUTING   │ ← Opacity pulse on charts. Slider labels update instantly.
└──────┬───────┘    WorkerOrchestrator handles stale responses (D-29).
       │
       ▼
┌──────────────┐
│  UPDATED     │ ← Charts render new projections (<200ms). Household impact
│              │    updates via interpolation between scenarios (D-01, D-02).
└──────────────┘

Error states (any state →):
┌──────────────┐
│ FETCH ERROR  │ ← Full-screen: "Impossible de charger les données." + "Réessayer" (D-30)
└──────────────┘
┌──────────────┐
│OOB WARNING   │ ← Chart area: "Paramètres hors domaine de validité" overlay (D-21)
└──────────────┘    WarningMessage text displayed above charts.
```

## URL State Encoding

Per D-23: Single `?state=<base64>` query parameter.

Encoded fields:
- `s`: selected scenario ID (e.g., `"baseline-2025"`) — null means no scenario selected
- `p`: slider positions — `{ "ir": 5.0, "is": -2.0, "tva": 10.0, "cotisations": 0.0, "depenses": -3.0 }` as percentage changes from baseline
- `f`: selected household profile index (0=modeste, 1=médian, 2=aisé — default 1)
- `a`: advanced mode toggle state (boolean — default false)

Example:
```
?state=eyJzIjoiYmFzZWxpbmUtMjAyNSIsInAiOnsiaXIiOjAsImlzIjowLCJ0dmEiOjAsImNvdGlzYXRpb25zIjowLCJkZXBlbnNlcyI6MH0sImYiOjEsImEiOiBmYWxzZX0=
```
Decoded: `{"s":"baseline-2025","p":{"ir":0,"is":0,"tva":0,"cotisations":0,"depenses":0},"f":1,"a":false}`

On load: Parse → restore scenario selection (triggers simulation) → restore slider positions → restore profile/advanced state.

## Accessibility Requirements (Phase 3 Scope)

Phase 3 implements the core RGAA 4 criteria. Full 106-criteria audit is deferred to Phase 5.

| Requirement | Contract | Verification |
|-------------|----------|--------------|
| A11Y-01 | SVG charts: `role="img"`, `aria-labelledby` | axe-core + Playwright assertions |
| A11Y-02 | HTML `<table>` with `<th scope>` adjacent to each chart | axe-core + manual screen reader test |
| A11Y-03 | Pattern fills + deuteranopia-safe colors for all 4 chart series | Visual review + Playwright color-blindness emulation |
| A11Y-04 | No animation >5s in this phase. Opacity pulse (300ms) exempt. | n/a |
| A11Y-05 | `useSlider` with full WAI-ARIA: `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, keyboard navigation, debounced drag-end announcements | Playwright ARIA assertions |
| A11Y-06 | axe-core in CI; Playwright `@playwright/test` accessibility assertions | CI gate (Vitest `expect().toHaveNoViolations()`) |
