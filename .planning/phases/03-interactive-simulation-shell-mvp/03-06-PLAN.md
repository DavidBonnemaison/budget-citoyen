<objective>
Build the impact display and macro chart visualization components. Delivers ImpactDisplay with three household profile pills (modeste, médian, aisé) showing ±€/mois impact with green/red color coding and the D-04 footnote. Builds a responsive 2×2 ChartGrid rendering the four Vega-Lite specs via vega-embed with SVG output, each wrapped in a ChartCell providing role="img" + aria-labelledby (A11Y-01), an HTML table fallback with th scope for screen readers (A11Y-02), and out-of-bounds greyed overlay with warning text (D-21).

Output: Five React components in `webapp/src/components/` — ImpactDisplay, ImpactPill, ChartGrid, ChartCell, ChartTableFallback — all using Tailwind tokens and vega-embed for SVG rendering.

| Boundary | Description |
|----------|-------------|
| MacroResult → Vega-Lite spec data | Numeric trajectory arrays transformed into {year, value} objects for chart rendering |
| SVG pattern defs → document DOM | CHART_PATTERNS_SVG injected via dangerouslySetInnerHTML — string is statically defined in source, not user-constructable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Tampering | XSS via CHART_PATTERNS_SVG injection | mitigate | CHART_PATTERNS_SVG is a const string defined in charts/patterns.ts — no user input enters the SVG markup. Verify no string interpolation or template literals with user data in the patterns string |
| T-03-12 | Tampering | Vega-Lite spec data poisoning via MacroResult | mitigate | MacroResult trajectory arrays contain Float64 values from macro-interpolate engine. Values are always finite numbers or the entire result is null. Vega-Lite renders numbers as text in data cells — no HTML injection surface (RESEARCH.md T-03-02) |
| T-03-13 | Information Disclosure | ChartTableFallback exposes trajectory data | accept | ChartTableFallback renders trajectory data in an sr-only table for screen readers. This is public-facing aggregate projection data — not PII. Required for A11Y-02 compliance |
