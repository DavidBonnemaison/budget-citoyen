<objective>
Build the onboarding and scenario selection components that form the first citizen touch points. Delivers a branded SplashScreen with phase-based progress tracking during asset fetch and worker init (D-27), a full-screen ErrorScreen with retry for fetch failures (D-30), and a responsive ScenarioGrid with selectable ScenarioCards implementing the primary flow: scenario selection first, sliders second (D-01, D-07).

Purpose: These four components establish the citizen's first impression of the application. The splash-to-preselect transition must feel deliberate and informative. The scenario grid is the entry point for all simulation interaction — every other interactive component (sliders, impact, charts) is disabled until a scenario is selected (D-28).
Output: Four React components in `webapp/src/components/` — SplashScreen, ErrorScreen, ScenarioGrid, ScenarioCard — all using Tailwind theme tokens with French copy matching the UI-SPEC contract.
</objective>

export function ScenarioGrid({ scenarios, selectedId, onSelect }: ScenarioGridProps) {
  return (
    <section aria-label="Scénarios disponibles">
      <h2>Choisissez un scénario pour commencer</h2>
      <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
