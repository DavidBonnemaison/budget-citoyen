Implement the LeverSlider component following the RESEARCH.md "Full Slider Component" code example (lines 560-673) as the PRIMARY source. This is a direct port with Budget Citoyen-specific theming.

**Key implementation points from RESEARCH.md pattern:**

1. **State management:** Use `useSliderState` from react-stately with { value: [defaultValue], minValue, maxValue, step, onChange, onChangeEnd, label, numberFormatter, isDisabled }

2. **Accessibility hooks:** Use `useSlider` from react-aria for groupProps/trackProps/labelProps/outputProps. Use `useSliderThumb` for thumbProps/inputProps with index:0, trackRef, inputRef.

3. **Number formatter:** `useMemo(() => new Intl.NumberFormat('fr-FR', { style: 'percent', signDisplay: 'always', maximumFractionDigits: 0 }), [])`

4. **Transition handling (RESEARCH.md Pitfall 3):**
   - `onChange`: calls `onValueChange(v)` directly (synchronous — instant label updates, D-15)
   - `onChangeEnd`: wraps `onDragEnd(v)` in `startTransition(() => onDragEnd(v))` for non-blocking computation

5. **Track gradient (inline style):** Compute percentage from state.values[0] relative to minValue/maxValue range. Apply `background: linear-gradient(to right, #1E3A5F 0%, #1E3A5F {pct}%, #CBD5E1 {pct}%, #CBD5E1 100%)`

6. **Thumb styling:** 44×44px (w-11 h-11), rounded-full, bg-primary (Tailwind token), shadow-md, positioned with left: `{pct}%` via `transform: translate(-50%, -50%)`

7. **Baseline notch + "Actuel" label (D-13):** Only render when minValue ≤ 0 ≤ maxValue. Position both at the 0% point calculated as `((-minValue) / (maxValue - minValue)) * 100%`. Notch: thin vertical line. Label: "Actuel" text below with `transform: translateX(-50%)`.

8. **Hidden native input:** Per React Aria pattern — `<input {...inputProps} ref={inputRef} />` for touch screen readers. This is mandatory per RESEARCH.md "Don't Hand-Roll" — React Aria handles touch screen readers via the hidden input.

9. **Disabled state (D-28):** When disabled=true, apply opacity-50 cursor-not-allowed to track, hide thumb visual, pass isDisabled to useSliderState.

10. **Loading state:** Add `animate-pulse` CSS class to track when `isPending` from useTransition is true (during onDragEnd computation, D-29).

Follow the PATTERNS.md conventions: 3-line file banner, section divider comments for large files, Tailwind utility classes only, no CSS modules.
