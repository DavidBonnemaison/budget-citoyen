<task id="10-02" name="Implement TypeScript macro interpolation engine" rule_category="Addition">
<description>
Create webapp/src/engine/macro-interpolate.ts replacing wasm-macro/src/interpolate.rs:

1. isInsideHull(point, equations): for each hyperplane [a1,a2,a3,b], compute dot product. Return false if any exceeds 1e-10 tolerance.

2. interpolateAtPoint(matrix, tax, spend, horizon):
   - Input validation: isFinite, tax > 0, spend > 0, horizon in [1,5]
   - Convex hull gating via isInsideHull
   - Binary search on breakpoints for surrounding grid cell indices
   - Compute fractional weights (tx, ts, th) per dimension
   - Extract 2^3 = 8 corner grid values at all 4 feature indices
   - Trilinear blend: weighted average of 8 corners per feature
   - Return MacroResult with single-element vectors, or null if out of bounds

3. projectTrajectory(matrix, tax, spend, years):
   - Loop year 1..years calling interpolateAtPoint
   - Accumulate into trajectory arrays (deficit, debt, gdpGrowth, employment)
   - Return MacroResult or null if any year fails

Create webapp/src/engine/__tests__/macro-interpolate.test.ts matching the 12 Rust tests from interpolation_tests.rs.
</description>
</task>
