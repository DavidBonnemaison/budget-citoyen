**Convex hull check (RESEARCH.md lines 671-681):**
```rust
fn is_inside_hull(&self, point: &[f64; 3]) -> bool {
    for eq in &self.hull_equations {
        let dot = eq[0] * point[0] + eq[1] * point[1] + eq[2] * point[2] + eq[3];
        if dot > 1e-10 { return false; }
    }
    true
}
```
Each hull equation is `[a1, a2, a3, b]` from scipy.spatial.ConvexHull, representing the hyperplane `a1*x + a2*y + a3*z + b <= 0`.

**ShockMatrix grid dimensions (from Phase 1):**
- Dimension 0 (tax_rate): 10-15 breakpoints, representing reform multiplier (0.5× to 2.0× reference rate)
- Dimension 1 (spend_level): 10-15 breakpoints, representing spending level (0.7× to 1.5× reference)
- Dimension 2 (horizon): 5 breakpoints, years 1-5
- Output variables: 4 per grid cell [gdp_growth, employment_change, deficit_change, debt_to_gdp_ratio]

**Grid data layout: C-order flattened `Vec<f64>` with shape (n_tax × n_spend × n_horizon × 4)**
