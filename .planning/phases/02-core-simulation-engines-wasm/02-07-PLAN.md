<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JS caller → WASM (ScenarioCache::new) | Untrusted JSON string for scenario data. Must validate via serde deserialization + version check. |
| JS caller → WASM (ScenarioCache::get_result) | Untrusted scenario_id and profile_id strings. Must handle unknown keys gracefully (return null, never panic). |
| JS caller → WASM (MacroEngine::interpolate) | Untrusted f64 values from JavaScript sliders. Must validate finite + convex hull containment. |
| JS caller → WASM (MacroEngine::new) | Untrusted binary data for shock matrix. Must validate dimensions and bounds. |
| WASM → JS console (panic hook) | WASM panic must NOT dump linear memory contents to browser console (ASVS V7). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11 | Tampering | ScenarioCache::new (JSON deserialization) | mitigate | serde deserialization with strict type checking. Version tag validated. Empty scenarios rejected. Malformed JSON returns Err(JsValue). |
| T-02-12 | Tampering | ScenarioCache::get_result (unknown scenario/profile) | mitigate | Returns JsValue::NULL for unknown IDs — never panics, never exposes internal HashMap state. |
| T-02-13 | Information Disclosure | WASM panic hook | mitigate | `console_error_panic_hook` only in `#[cfg(debug_assertions)]`. Production builds: no console output. NEVER dump memory contents. |
| T-02-14 | Denial of Service | MacroEngine::interpolate with NaN/Infinity | mitigate | Validate all inputs with `.is_finite()` before interpn call. NaN/Infinity → hull check fails → returns JsValue::NULL. |
| T-02-15 | Information Disclosure | wasm-pack build output | mitigate | `[profile.release]` with `debug = false`. Verify pkg/ contains no `.map` files, no local filesystem paths. |
| T-02-16 | Elevation of Privilege | wasm-bindgen auto-generated JS | accept | wasm-bindgen generates trusted glue code. No user input evaluated as code. Risk accepted as standard WASM practice. |
</threat_model>
