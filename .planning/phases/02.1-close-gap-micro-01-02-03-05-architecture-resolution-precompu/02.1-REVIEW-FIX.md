### WR-03: `_estimate_aides` sets `aide_scales["apl"] = 1.0` when `reval == 0.0` — semantically empty assignment

**Files modified:** `packages/data-pipeline/src/scenarios/precompute.py`
**Applied fix:** Added `else` clause to handle non-zero revalorisation values: `aide_scales["apl"] = reval`. Previously, any non-zero APL revalorisation value was silently dropped (neither the `reval == 0.0` branch nor any other code set `aide_scales["apl"]`). Updated comment to clarify semantics: "0.0 = freeze (no change from baseline), > 0 = scale factor".

### WR-04: CI workflow version check for openfisca-france is a soft warning, not a hard gate

**Applied fix:** Changed `::warning` to `::error` and added `exit 1` after the error message. The OpenFisca version check now fails the CI job if the version is outside the expected range (159-199).

### IN-01: Parameter overrides shallow-copied with dict comprehension

**Files modified:** `packages/data-pipeline/src/scenarios/precompute.py`
**Applied fix:** Added `import copy as _copy` and changed the export dict comprehension to use `_copy.deepcopy(v)` for non-boolean values (booleans are converted to `1.0`/`0.0` inline). This prevents downstream mutations from corrupting the source `ScenarioDefinition` parameter_overrides.

### IN-03: `_compute_ir_bareme` hardcodes 2025 French tax brackets

**Files modified:** `packages/data-pipeline/src/scenarios/precompute.py`
**Applied fix:** Added a comment above the hardcoded brackets acknowledging the design decision and recommending a CI gate cross-validation against `tax-rules/parameters/impot_revenu/bareme/*.yaml` to prevent drift when tax law changes.

### IN-04: `parameterOverrides` schema allows arbitrary objects

**Files modified:** `packages/data-pipeline/src/scenarios/schemas/scenarios.schema.json`
**Applied fix:** Expanded `parameterOverrides` from `{ "type": "object" }` to a full property-level schema with type constraints for all known override keys:
- `impot_revenu.bareme`: nested object with `brackets` array of `{rate, threshold}` dicts
- `tva.taux_normal`, `tva.taux_intermediaire`: number 0-1
- `cotisations.scale`, `prestations_sociales.*`: number ≥ 0
- `revenu_universel.montant_mensuel`: number ≥ 0
- `revenu_universel.remplace_aides`: boolean or number (post-CR-04 export)

Added `tva.taux_intermediaire` (used by consolidation-2025) to the property list. Used `additionalProperties: false` to reject unknown override keys.
